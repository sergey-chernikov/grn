Gnome ReadNews Key Bindings

Grouplist
Enter Open current group
Ctrl-Up Previous unread group
Ctrl-Down Next unread group
Right Open current group

Threadlist
Enter Open current message
Ctrl-Up Previous unread message
Shift-Up Previous unread thread
Ctrl-Down Next unread message
Shift-Down Next unread thread
Left Return to grouplist
Right Open current message
Ctrl-Left Scroll left
Ctrl-Right Scroll right

Message view
Ctrl-Up Scroll 1/4 page up
Shift-Up Scroll 1/2 page up
Ctrl-Down Scroll 1/4 page down
Shift-Down Scroll 1/2 page down
Left Return to threadlist
Right Open next unread message
MB4 Scroll 1/4 page up
Ctrl-MB4 Scroll 1 page up
Shift-MB4 Scroll 1/2 page up
MB5 Scroll 1/4 page down
Ctrl-MB5 Scroll 1 page down
Shift-MB5 Scroll 1/2 page down
